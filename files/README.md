# 🧪 Cheminformatics Virtual Laboratory

**SRM Institute of Science and Technology, Tiruchirappalli**
School of Sciences · Division of Chemistry

## Aim

To develop a foundational understanding of Cheminformatics by using
computational tools to represent, visualize and analyze chemical structures.

## Learning Objectives

Students will be able to

- Convert molecular representations using SMILES.
- Visualize molecular structures in 2D and 3D.
- Calculate molecular descriptors.
- Check drug-likeness (Lipinski / Veber rules).
- Understand structure–property relationships.

## Pages

| Page | What it does |
|---|---|
| 🏠 Home | Overview, quick-start buttons, one-click example molecules |
| 📖 Theory | SMILES rules, descriptors, drug-likeness, 3D models |
| 🧪 Molecule Lab | One input → 2D structure, 3D model, properties, drug-likeness, CSV/PDF downloads |
| ⚖️ Compare Molecules | Table + charts for many molecules, CSV download |
| 📝 Assessment | 12 questions with answer review and explanations |
| 📄 Project Report | Combined multi-molecule PDF with student details |

## Molecular Descriptors

Molecular Weight · LogP · TPSA · H-bond Donors · H-bond Acceptors ·
Rotatable Bonds · Ring Count · σ/π bond counts · Fraction Csp3 · Molar Refractivity

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

Keep `srm_logo.jpeg` and the `.streamlit/` folder next to `app.py`.
